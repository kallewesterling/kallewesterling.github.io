02 · Projects

Tools I build for developers and educators

Small, sharp tools that came out of real friction in courses, demos and docs.

  • Security

    cvediff

    Compares the known CVEs in two container images side by side in the terminal. Answers one question fast: what changes if we swap this base image for a hardened one?

    • Python
    • Grype
    • CLI

    GitHub↗

  • Docs quality

    errata

    Finds broken code examples inside published course content, and keeps a dated record of the ones you can't fix yet. Courses stay live; the code in them shouldn't rot.

    • TypeScript
    • CI

    GitHub↗

  • Docs as code

    CodexMachina

    Extracts, runs and lints the code blocks in Markdown and HTML documentation, with output verification, so every example in the docs is one you can trust.

    • Go
    • Markdown

  • Speaking

    session-pacer

    A presenter view for timed talks, workshops and demos. Shows the notes for the current section, tells you when you're behind, and suggests what to cut.

    • HTML
    • JavaScript

  • Course ops

    syncjar

    Edit, preview and sync Skilljar course content locally, so course authors get a real git workflow instead of a web form.

    • Node.js
    • Skilljar API

    Docs↗GitHub↗

  • Course ops

    credjar

    Inspect, issue and revoke Credly badges from the command line, for certification programs that outgrow spreadsheets.

    • Node.js

From the classroom to developer relations

I still design learning the same way: start from where people get stuck, and remove that step.

Short bio

Full bio

Kalle Westerling is a Staff Developer Relations Engineer at Chainguard, where he creates courses, hands-on labs, workshops and live demos that help developers adopt secure container images and open-source libraries. He also builds open-source tools for developer educators, from testing code examples in published courses to pacing live sessions. Before Chainguard he was a research software engineer and research application manager at the Alan Turing Institute, and before that he led national coding and research training programs at CUNY, where he earned a PhD in digital humanities. He still approaches technical education as a teacher first.
