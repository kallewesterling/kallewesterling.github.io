The setup I write, build and demo with. Inspired by [uses.tech](https://uses.tech).

## Hardware

- **Laptop:** Lenovo ThinkPad T14 Gen 3, AMD Ryzen 5 PRO 6650U, 16 GB RAM.

## Desktop

- **OS:** [Omarchy](https://omarchy.org), an opinionated Arch Linux setup on the [Hyprland](https://hyprland.org) tiling window manager.

## Building

- **Editor:** VS Code.
- **Agent:** [Claude Code](https://claude.com/claude-code).
- **Python:** [uv](https://docs.astral.sh/uv/).
- **Containers:** Docker.

## Teaching and live demos

- **Pacing live sessions:** my own [session-pacer](/session-pacer/).

## This site

Built with [Hugo](https://gohugo.io) and hosted on GitHub Pages. Most of the content lives in YAML data files. A plain-text version for language models is at [/llms.txt](/llms.txt).
